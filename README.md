# Study MBBS Abroad Landing Page

A responsive landing page for students interested in pursuing MBBS abroad. Built with HTML, Tailwind CSS, and JavaScript.

# Features
- Responsive design for all devices
- Country listings for MBBS programs
- Program details and benefits
- Lead generation form with validation
- SEO optimized
- Fast loading

# Setup
1. Clone the repository
2. Open index.html in your browser
3. For development, install live-server (optional)

# Technologies Used
- HTML5
- Tailwind CSS
- JavaScript
- Font Awesome Icons
